=== Aktualisierung des Sparrechners

Es besteht die Möglichkeit, verschiedene Kostenkomponenten für den Betrieb von Microsoft SQL Server Workloads wie Storage, Compute, SQL-Lizenz, Snapshots und Klone für Ihre Datenbank-Workloads auf FSx for ONTAP File Systemen mit Elastic Block Store (EBS), FSx for Windows File Server und On-Premises Storage zu vergleichen, wobei ausschließlich Ansichts-, Planungs- und Analyseberechtigungen erforderlich sind.
